DISCIPLINE

Portfolio guardrails

  • Do not sell only because the share price falls.
  • Review immediately for promoter pledge, major promoter exit or unexplained dilution.
  • Review auditor qualifications, going-concern language, defaults and sharp rating downgrades.
  • Watch operating cash flow against reported profit over multiple annual periods.
  • Verify material news in NSE/BSE/company/rating-agency disclosures before acting.
DATA QUALITY

Source hierarchy

  1. NSE/BSE regulatory filings and audited statements
  2. Company investor-relations disclosures
  3. Credit-rating agency rationales
  4. Market-data providers for cross-checking
  5. News aggregators for discovery only
SYSTEM

How this dashboard updates

GitHub Actions refreshes the public market-data/news snapshot on weekdays. Cloudflare Pages then redeploys this static dashboard automatically. The Python Streamlit research application remains in the repository for deeper local analysis.
